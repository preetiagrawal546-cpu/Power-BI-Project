# Power-BI-Project
This repository displays Power BI project to showcase dashboarding skills, help build interactive dashboards and take insightful data-driven business decisions

# Project Overview

This project is a Power BI learning and portfolio project inspired by the real estate operations of Avneesh Realty Group. It explores how business intelligence and data visualization can help monitor operational performance, understand sales and customer funnels, track project progress, and support data-driven decision-making.

The dashboard concept covers lead management, bookings, collections, inventory, project progress, and agent productivity.

Data confidentiality notice: All datasets and figures included in this repository are fictional, synthetic, or altered for educational and demonstration purposes only. They do not represent the actual operational or financial performance of Avneesh Realty Group. Actual business figures are confidential and have not been disclosed.

# Objectives
  Practice designing an end-to-end Power BI dashboard from a business scenario.
  Translate operational questions into measurable KPIs.
  Develop data modelling and relationship-building skills.
  Create DAX measures for operational and financial monitoring.
  Explore how dashboard insights can help identify process bottlenecks and areas for further investigation.

# Getting Started

\
Clone or download this repository.
\
Open Power BI Desktop.
\
Select Home → Get Data → Excel.
\
Import the tables from Avneesh_Realty_PowerBI_Data.xlsx.
\
Create the relationships described in README_Setup.txt.
\
Add the measures from DAX_Measures.txt.
\
Build the report pages using the dashboard scope above.
\
Review the KPI definitions and assumptions before using the report with any real business data.

# Learning Outcome

This project provides hands-on practice in structuring business data, defining operational KPIs, creating DAX calculations, and designing a dashboard that connects performance monitoring with business questions. It is a learning exercise and not an official company report.
